3. Appointment Booking Flow

sequenceDiagram participant P as Patient participant F as Frontend participant B as Backend API participant D as MySQL Database P->>F: Select Doctor & Time Slot F->>B: POST /api/patient/appointments B->>B: Verify JWT Token B->>B: Check Role = 'patient' B->>D: Check for Time Conflicts D-->>B: Conflict Check Result alt Time Slot Available B->>D: INSERT INTO Appointment D-->>B: Appointment ID B->>D: INSERT INTO PatientsAttendAppointments B->>D: INSERT INTO Diagnose B-->>F: Success Response F-->>P: Appointment Confirmed else Time Slot Booked B-->>F: 400 Error F-->>P: Time Slot Unavailable end Note over P,D: Appointment Status: 'NotDone'

4. Diagnosis & Billing Flow

sequenceDiagram participant Doc as Doctor participant Cash as Cashier participant B as Backend API participant D as MySQL Database Doc->>B: PUT /api/doctor/appointments/:id/diagnosis B->>B: Verify JWT & Role B->>D: UPDATE Diagnose SET diagnosis, prescription B->>D: UPDATE Appointment SET status = 'Done' D-->>B: Success B-->>Doc: Diagnosis Updated Note over Doc,D: Appointment Status: 'Done' Cash->>B: POST /api/cashier/billing B->>B: Verify JWT & Role B->>D: INSERT INTO Billing (status: 'Pending') D-->>B: Billing ID B-->>Cash: Bill Created Cash->>B: PUT /api/cashier/billing/:id/payment B->>B: Verify JWT & Role B->>D: UPDATE Billing SET payment_status = 'Paid' D-->>B: Success B-->>Cash: Payment Recorded
